# Montessori GitHub Site

نسخة موقع تعريفية ثابتة جاهزة للرفع على GitHub Pages.

## التشغيل المحلي

افتح ملف `index.html` مباشرة في المتصفح. لا تحتاج إلى Node.js أو قاعدة بيانات.

## الرفع على GitHub

1. أنشئ Repository جديدًا على GitHub.
2. ارفع `index.html` ومجلد `assets`.
3. من `Settings` ثم `Pages` اختر `Deploy from a branch`.
4. اختر فرع `main` ومجلد `/root` ثم اضغط `Save`.
5. بعد دقائق سيظهر رابط الموقع.

## ملاحظة

البريد الموجود في الصفحة هو `info@montessori-ksa.com`. عدّله داخل `index.html` إذا كان لديك بريد مختلف.
